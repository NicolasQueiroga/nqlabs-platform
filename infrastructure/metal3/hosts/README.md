# BareMetalHost Inventory

## How to add a machine

1. **Add a row to `inventory.csv`** with the machine's details:

   ```csv
   staging-worker-01,106,BC:24:11:15:00:21,redfish-virtualmedia+https://192.168.15.20:8443/redfish/v1/Systems/106,nqlabs-staging,worker,proxmox,true,true,4,8192,proxmox-shared
   ```

2. **Run the generator:**

   ```bash
   cd infrastructure/metal3/hosts
   ./generate.sh
   ```

3. **Commit and push:**

   ```bash
   git add *.yaml inventory.csv
   git commit -m "add <name> to BareMetalHost inventory"
   git push
   ```

ArgoCD will automatically sync the new BareMetalHost to the cluster.

## Inventory columns

| Column | Description |
|--------|-------------|
| `name` | BareMetalHost name (unique, DNS-safe) |
| `vmid` | Proxmox VM ID (e.g., `104`) or `physical` for bare metal |
| `mac` | Boot MAC address (must match the VM/NUC network config) |
| `bmc_address` | Redfish/IPMI endpoint |
| `cluster` | Target cluster label (`nqlabs-management`, `nqlabs-staging`, `nqlabs-production`) |
| `role` | Node role (`control-plane` or `worker`) |
| `provider` | Hardware provider (`proxmox` or `physical`) |
| `accepted` | Whether Metal3 should manage this host (`true`/`false`) |
| `online` | Whether the host should be powered on (`true`/`false`) |
| `cores` | CPU cores (informational) |
| `memory` | Memory in MB (informational) |
| `bmc_credentials` | BMC Secret name: `proxmox-shared` for Proxmox VMs, `<name>-bmc` for physical NUCs |

## BMC credentials

### Proxmox VMs

All Proxmox VMs share a single Kubernetes Secret (`proxmox-bmc`) since they
all use the same proxmox-redfish daemon with the same Proxmox credentials.
The shared Secret is generated by `generate.sh`.

### Physical NUCs

Each physical NUC has its own BMC credentials. Create a Secret manually:

```yaml
# nuc-01-bmc.yaml (not generated — manage manually)
---
apiVersion: v1
kind: Secret
metadata:
  name: nuc-01-bmc
  namespace: metal3
type: Opaque
data:
  username: <base64>
  password: <base64>
```

Then reference it in `inventory.csv` via the `bmc_credentials` column:

```csv
nuc-01,physical,AA:BB:CC:DD:EE:FF,redfish-virtualmedia+https://192.168.15.50:8443/redfish/v1/Systems/1,nqlabs-production,worker,physical,true,true,4,16384,nuc-01-bmc
```

## Generated files

- `proxmox-bmc-secret.yaml` — shared BMC Secret for all Proxmox VMs
- `<name>.yaml` — one BareMetalHost per row in `inventory.csv`

All generated files have a header comment: "Generated from inventory.csv — do not edit directly."
