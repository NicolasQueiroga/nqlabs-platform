# Demo service Terraform definition

This is the Terraform definition for the demo service environment files.

It mirrors the currently validated service factory state:

| Environment | Image |
|-------------|-------|
| staging | `ghcr.io/nicolasqueiroga/nqlabs-demo:sha-e742e7897a80` |
| production | `ghcr.io/nicolasqueiroga/nqlabs-demo:sha-aec3a454e4aa` |

Mac lab namespaces generated by default:

| Environment | Namespace |
|-------------|-----------|
| staging | `demo-staging` |
| production | `demo-production` |

Workflow:

```bash
terraform -chdir=terraform/services/demo init
terraform -chdir=terraform/services/demo plan
terraform -chdir=terraform/services/demo apply
```

Then commit the generated changes under `apps/demo/environments/` and open/merge a
PR. ArgoCD remains the deployment authority.
